# Verifier A: packed binary symplectic checker

This directory contains a dependency-free Python 3 verifier for a literal
binary qubit stabilizer matrix

```text
H = [X_1 ... X_n | Z_1 ... Z_n].
```

It is a checker and calibration package only.  It does not search for a
`[[14,3,5]]` code.

## Exact checks

For an input with `r` rows, `verifier.py`:

1. checks that every row has the same positive even length and contains only
   integer bits;
2. packs bit `i` as `X_i` and bit `n+i` as `Z_i`;
3. computes `rank(H)` over `GF(2)` and rejects dependent rows;
4. checks every pair using
   `<(x|z),(x'|z')>_s = x*z' + z*x' mod 2`;
5. constructs `C^{perp_s}` as the ordinary nullspace of the equations
   `[Z|X] v^T = 0`;
6. enumerates every one of its `2^(2n-r) = 2^(n+k)` vectors in Gray-code
   order;
7. tests membership in `row(H)` using a separate high-pivot packed reducer;
8. computes the complete stabilizer and logical Pauli-weight distributions;
9. returns the exact minimum weight in `C^{perp_s} \ C` and a witness.

For a valid target-sized input, the checker therefore enumerates exactly
`2^17 = 131072` normalizer vectors and expects exactly `2^11 = 2048` of them
to be stabilizers.

The nullspace path and repeated membership path deliberately do not share an
echelon representation.  The randomized tests add a third path that enumerates
all `4^n` Paulis and materializes the stabilizer span for small `n`.

Pauli phases do not occur in the binary distance calculation.  Independent
isotropic binary rows define the required phase-free stabilizer subspace; the
checker does not claim to verify a separately supplied signed Pauli group.

## Input

Use one `X bits | Z bits` row per line.  Whitespace, commas, square brackets,
and comments beginning with `#` are accepted.  For example:

```text
# XZZXI and IXZZX
10010|01100
01001|00110
```

The parser rejects unequal halves, ragged rows, non-binary values, and odd
widths.  The report's `matrix_sha256` hashes the canonical compact rows,
including a final newline, so comments and cosmetic whitespace do not alter
the identifier.

## Commands

Run the deterministic regression and brute-force cross-check suite:

```bash
cd verifier_a
python3 test_verifier.py
```

Verify the standard five-qubit code:

```bash
python3 verifier.py fixtures/five_qubit_5_1_3.txt \
  --expect-n 5 --expect-rank 4 --expect-k 1 --require-distance 3
```

Verify the independently transcribed code-table construction:

```bash
python3 verifier.py fixtures/table_14_3_4.txt \
  --expect-n 14 --expect-rank 11 --expect-k 3 --require-distance 4
```

Use `--compact` for single-line JSON.  To certify a proposed target matrix,
the corresponding claim command is:

```bash
python3 verifier.py candidate.txt \
  --expect-n 14 --expect-rank 11 --expect-k 3 --require-distance 5
```

A structural or claim failure is written to standard error as
`VERIFICATION FAILED: ...` and returns exit status 1.

## Calibration fixtures and exact results

`fixtures/five_qubit_5_1_3.txt` is the standard cyclic stabilizer generated by
`XZZXI`, `IXZZX`, `XIXZZ`, and `ZXIXZ`.

`fixtures/table_14_3_4.txt` was independently transcribed on 2026-07-24 from
the maintained code-table page:

<https://codetables.de/QECC.php?k=3&n=14&q=4>

The exact checked results are:

| fixture | `(n,rank,k)` | `dim(C^perp)` | distance | logical weight distribution |
| --- | --- | --- | --- | --- |
| five-qubit | `(5,4,1)` | 6 | 3 | `[0,0,0,30,0,18]` |
| table construction | `(14,11,3)` | 17 | 4 | `[0,0,0,0,105,588,2079,6216,14322,24192,30198,27384,16821,6132,987]` |
| fixed ancilla + five-qubit | `(6,5,1)` | 7 | 3 | `[0,0,0,30,30,18,18]` |
| unfixed qubit example | `(2,1,1)` | 3 | 1 | `[0,3,3]` |

Canonical matrix hashes:

```text
five-qubit:
136a761d188e9ec27f0df73a83f5a1a65f38f9e80483f9a6b55fd244f8a91cf5

table construction:
b5bf2521d0e7d3561e8229809bea27b3665419cf0db4d63769e207fc312e85d7
```

The table construction is degenerate: its stabilizer weight distribution is

```text
[1,2,1,0,0,6,18,72,249,454,485,376,246,114,24].
```

In particular, it has two nonidentity weight-one stabilizers.  They are
correctly counted as stabilizers rather than low-weight logical operators.
The separate `degenerate_6_1_3.txt` fixture makes the same distinction with a
transparent `ZIIIII` generator.

## Negative tests

The deterministic suite confirms rejection or correct classification of:

- a duplicate-row corruption of the table matrix;
- the one-bit mutation `H[0][0] ^= 1`, which preserves full row rank but makes
  table rows 0 and 1 anticommute;
- a valid `[[2,1,1]]` stabilizer when a distance-at-least-two claim is imposed;
- malformed widths, ragged rows, non-bits, and Boolean values;
- a weight-one stabilizer in a degenerate `[[6,1,3]]` code, which must not be
  counted as logical.

The final randomized test uses seed `14003005` and checks 30 independently
generated isotropic matrices for `2 <= n <= 5`.  Its brute-force reference
path visits all `4^n` binary Paulis and does not use the verifier's packing,
symplectic, weight, membership, or nullspace helpers.

The frozen deterministic console transcript is in
`validation_output.txt`.
